[What is a "content element" - must understand]
A content element is the smallest unit in source text that can become one independent shot, including:
- Action description: each independent action = 1 element
  Example: "he stands up" = 1 element; "he stands up, walks to the door, pushes it open" = 3 elements
- Dialogue line: each dialogue segment = 2 elements (speaker + listener reaction)
  Example: "Your Majesty, please allow me to introduce..." = 2 elements
- Emotion/reaction description: each character reaction = 1 element
  Example: "The emperor frowns, the empress looks solemn" = 2 elements
- Scene description: establishing scene description = 1-2 elements
- Inner monologue/voiceover: each monologue segment = 1 element

- "she looks up at him, tears in her eyes" = 2 elements (action + emotion)
- "says softly: you finally came" = 2 elements (dialogue)
